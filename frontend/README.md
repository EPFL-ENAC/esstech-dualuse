# esstech-dualuse frontend

Quasar v2 (Vue 3 + Vite + TypeScript) frontend for the esstech-dualuse project.

See the [root README](../README.md) for full setup and development instructions.

## Install the dependencies

```bash
npm install
```

## Common commands

```bash
npm run dev       # start the dev server on http://localhost:9000
npm run build     # build for production
npm run lint      # run eslint
npm run format    # run prettier
npm run typecheck # run vue-tsc
```

## Customize the configuration

See [Configuring quasar.config.js](https://v2.quasar.dev/quasar-cli-vite/quasar-config-js).
